v0.2.3 — агент перестал пытаться делать скриншот через shell.

- Добавлена кнопка «Проверить MCP в OpenCode»: показывает статус сервера phone прямо в приложении (должно быть `connected`).
- Обновлён `phone-opencode.json`: подключён файл инструкций `phone-instructions.md`, который запрещает агенту использовать `screencap`/`input tap` через shell и предписывает работать через `tools.phone.*`.
- Кнопка «Копировать: конфиг» теперь копирует загрузку обоих файлов (opencode.json и phone-instructions.md).
- Улучшена диагностика: прогресс при подключении, ожидание ответа показывается в чате, ответ ищется по новым ID сообщений, а не по времени.

ВАЖНО: после обновления конфига перезапусти `opencode serve` в Termux — конфиг читается при старте. Затем `opencode mcp list` должен показать `phone connected`.
